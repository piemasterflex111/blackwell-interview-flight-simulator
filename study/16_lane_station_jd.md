Manufacturing Test Engineer — Battery Module Production

We're looking for an engineer who has designed and validated multi-channel automated test stations for hardware manufacturing. You should have experience with serial communication protocols (RS-422, UART), firmware flashing workflows, telemetry data acquisition, and bringing up new test equipment from zero to production.

Key requirements:
- Design and integrate automated test stations for hardware production
- Implement serial communication (RS-422, UART, CAN) for test equipment control
- Develop firmware flashing and validation workflows for production PCBA
- Build end-to-end test validation from DUT to test software to data logging
- Debug hardware test failures across the station: DUT, fixture, cabling, test software
- Validate multi-channel parallel test operations and identify scaling limits
- Work with LabVIEW, Python, or similar test automation frameworks
- Document test procedures, failure modes, and station bring-up notes
- Interface with EGSE teams on test station build specifications

Preferred:
- Experience with spacecraft or high-reliability battery module manufacturing
- Parallel/parallel test station design
- Custom fixture and cable harness integration for multi-DUT test
- Production cycle time optimization through parallel test
